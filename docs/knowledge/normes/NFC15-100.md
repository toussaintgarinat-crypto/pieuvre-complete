# NF C 15-100 - Norme Française des Installations Électriques

## Vue d'ensemble

La norme NF C 15-100 définit les règles d'installation électrique basse tension dans les bâtiments d'habitation en France.

## Principes fondamentaux

### 1. Taux de remplissage des gaines

| Paramètre | Valeur | Description |
|-----------|-------|-------------|
| Taux remplissage max | 40% | 1/3 de la surface interne |
| Formule | `surface_gaine = surface_cables / 0.4` | Calcul surface nécessaire |

### 2. Nombre de prises par circuit

| Type | Maximum | Note |
|------|---------|------|
| Prises 16A | 8 | Par circuit d'alimentation |
| Prises 20A | 8 | Circuit dédié possible |
| Lumières | Illimité | Selon disjoncteur |

### 3. Sections de câbles

| Usage | Section | Intensité max |
|------|---------|--------------|
| Éclairage | 1.5mm² | 10A |
| Prises 16A | 1.5mm² | 16A |
| Prises 20A | 2.5mm² | 20A |
| Appareils | 2.5-6mm² | Selon appareil |
| Tableau | 6-10mm² | Alimentation générale |

### 4. Gaines - Diamètres standards

| Ø interne | Usage |
|------------|-------|
| 16mm | 1-2 circuits lumières |
| 20mm | 2-4 circuits prises |
| 25mm | 6+ circuits |
| 32mm | Tableau/coupe-circuit |
| 40mm | Distribution principale |
| 50-63mm | Gaines principales |

## Application dans Pieuvre Auto

- Le système calcule automatiquement le Ø gaine minimal
- Respect du taux de 40% de remplissage
- Adaptation si client refuse certaines gaines (Ø16)
- Mapping des types de circuits selon norme
